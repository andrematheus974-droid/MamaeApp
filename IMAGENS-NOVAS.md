# Imagens novas do aplicativo Mãe Presente

O aplicativo já funciona com as fotos que você tem. Cada imagem desta lista **entra sozinha** quando você salvar o arquivo com o nome certo na pasta indicada. Não precisa mexer em código. Enquanto a imagem não existir, o aplicativo usa uma foto reserva (ou um desenho simples).

**Formato:** .webp, deitada (4:3), cerca de 1000 x 750, até 120 KB.

## Texto base (cole antes de cada cena)

## Foto dentro de uma tela de lição

Qualquer tela de qualquer lição aceita foto. Salve em `imagens/licoes/` com o nome `<modulo>-<lição>-<tela>.webp`. Exemplo: `brinquedos-2-3.webp` é a 3ª tela da 2ª lição do módulo Brinquedos.
